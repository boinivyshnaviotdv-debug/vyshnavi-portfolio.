B. VYSHNAVI — CSE STUDENT PORTFOLIO
===================================

FILES
-----
index.html  - website content and sections
style.css   - dark theme, layout, responsive styles, animations
script.js   - mobile menu, scroll reveal, active navigation, contact form

HOW TO RUN
----------
1. Extract this ZIP file.
2. Open the vyshnavi-portfolio folder.
3. Double-click index.html, or open it with a browser.
4. To edit the code, open the folder in Visual Studio Code.

BEFORE PUBLISHING — IMPORTANT
-----------------------------
1. Search index.html for text in [square brackets] and replace it with your real details.
2. Add your own photo by replacing the avatar-placeholder block in index.html with:
   <img class="profile-photo" src="assets/profile.jpg" alt="B. Vyshnavi">
   Then add this CSS:
   .profile-photo { width: 100%; height: 185px; object-fit: cover; border-radius: 15px; }
   Put your photo at assets/profile.jpg (create the assets folder first).
3. Replace your.email@example.com in index.html and script.js with your real email.
4. Replace your-username in the GitHub and LinkedIn links.
5. Replace project links (#) with working repository/live-demo URLs.
6. The project descriptions are starter text, not a claim that each project is finished. Keep only projects you actually built and update each description/technology list to match your work.
7. The contact form currently opens the visitor's default email application. It does not send messages directly from the website. For a server-based form, connect a service such as Formspree or your own backend.
8. Google Fonts needs an internet connection; system fonts will be used if unavailable.

PUBLISH WITH GITHUB PAGES
-------------------------
1. Create a GitHub repository, for example: vyshnavi-portfolio.
2. Upload index.html, style.css, script.js, and README.txt to the repository root.
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, choose the main branch and / (root), then Save.
5. Wait for GitHub Pages to publish your site and open the URL shown there.
